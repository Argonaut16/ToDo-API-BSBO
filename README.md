# ToDo API (FastAPI)

Учебный REST API для управления задачами (ToDo-лист), разработанный с использованием **FastAPI**.  
Проект реализован в рамках практической работы и демонстрирует основы построения API, валидации данных и работы с роутерами.

---

## 📌 Возможности API

- Создание задач
- Получение списка всех задач
- Поиск задач
- Обновление задачи
- Отметка задачи как выполненной
- Удаление задачи
- Получение статистики по задачам
- Классификация задач по матрице Эйзенхауэра (Q1–Q4)

---

## 🛠 Используемые технологии

- Python 3.10+
- FastAPI
- Pydantic
- Uvicorn
- In-memory хранилище (без базы данных)

## ▶ Запуск проекта

1. Установить зависимости:
```bash
pip install -r requirements.txt
```

2. Запустить сервер:
```bash
uvicorn main:app --reload
```

3. Открыть в браузере:
- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

---

## Основные эндпоинты

- `GET /api/v1/tasks` — получить все задачи  
- `POST /api/v1/tasks/` — создать задачу  
- `PUT /api/v1/tasks/{id}` — обновить задачу  
- `PATCH /api/v1/tasks/{id}/complete` — отметить задачу выполненной  
- `DELETE /api/v1/tasks/{id}` — удалить задачу  
- `GET /api/v1/stats` — статистика по задачам
